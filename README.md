# ⚡ SYNAPSE B2B — Raw Materials Wholesale & Pooled Co-Procurement Platform

A modern, high-performance B2B wholesale platform for small, medium, and large manufacturing enterprises to procure verified raw materials directly from industrial mills and refineries. Featuring **Pooled Co-Procurement** (collective group wholesale to cut factory costs), wholesale volume tiered pricing, Mill Test Certificate (MTC) datasheets, Incoterms logistics calculation, and instant corporate Purchase Order (PO) generation.

Designed with an authentic **Tiffany Blue (`#0abab5`) & Luxury Porcelain Light Theme**.

---

## 🌟 Key Features

1. **Pooled Group Co-Procurement ("Buy Together to Cut Costs")**:
   - Small and medium workshops aggregate raw material demand together into live dispatch batches.
   - Automatically unlocks Tier-1 enterprise mill discounts (up to 25% off) normally reserved for industrial conglomerates.
   - Live pool fill status indicator and countdown timers.

2. **Wholesale Tiered Volume Pricing**:
   - Dynamic real-time calculation based on Metric Tons (MT), Pallets, Drums, or Rolls.
   - Transparent price tiers with MOQ (Minimum Order Quantity) enforcement.

3. **Mill Direct Quality Assurance & MTC Inspection**:
   - Technical datasheets with chemical composition, yield strength, tensile rating, and tolerances.
   - Sourced directly from certified producers (ArcelorMittal, SABIC, Alcoa, Jindal, Toray, Mondi).
   - Instant sample testing order capability.

4. **Incoterms Logistics & Currency Matrix**:
   - Live switching between **CIF** (Destination Port), **FOB** (Origin Mill), and **EXW** (Factory Pickup).
   - Multi-currency support: USD ($), EUR (€), INR (₹), and GBP (£).

5. **Corporate Purchase Order (PO) & RFQ Bag**:
   - Instant digital PO generation with corporate tax, freight calculations, and printable formal PO sheet.
   - Autofill enterprise profile and authorization workflow.

6. **Authentic Tiffany Blue & Porcelain Aesthetics**:
   - Clean Robin Egg Blue (`#0abab5`) accents, subtle technical precision grid, and responsive design across desktop and mobile.

## 🏗️ Tech Stack

- **HTML5**: Semantic B2B enterprise structure.
- **Vanilla CSS3**: Design system with HSL tokens, Tiffany Blue palettes, backdrop filters, and micro-interactions.
- **Vanilla ES6 JavaScript**: Reactive cart state, pooled group logic, search and filtering, and PO generator.
- **Assets**: High-resolution local industrial photography for steel coils, HDPE polymers, aluminum billets, TMT rebar, industrial chemicals, electric motors, carbon fiber, and kraft linerboard.

## 🚀 Live Demo & Local Setup

### Running Locally
```bash
# Clone the repository
git clone https://github.com/Jenish-187/synapse-b2b.git
cd synapse-b2b

# Start a simple HTTP server
python -m http.server 3000

# Open in your browser
http://localhost:3000
```

### GitHub Pages Deployment
1. Go to repository **Settings** > **Pages**.
2. Under **Branch**, select `main` and root `/`.
3. Click **Save**. Your site will be live at:
   `https://Jenish-187.github.io/synapse-b2b/`
